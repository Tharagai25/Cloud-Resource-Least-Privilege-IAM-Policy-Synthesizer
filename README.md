# Cloud Resource Least-Privilege IAM Policy Synthesizer

## Overview

The Cloud Resource Least-Privilege IAM Policy Synthesizer is a cloud-based application that automatically generates resource-specific IAM policies based on the required permissions.

The system follows the Principle of Least Privilege by providing only the necessary permissions for a selected cloud resource, helping reduce excessive access and security risks.

## Problem Statement

Manually configuring IAM permissions can result in excessive access and potential security vulnerabilities.

## Proposed Solution

The application automates IAM policy generation by taking the cloud service, resource name, and required permission as inputs and generating a least-privilege IAM policy in JSON format.
